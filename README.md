# Stopwatch

An interactive stopwatch web application built with a clean interface and a green-themed design. It allows users to track time, manage laps, and view lap statistics.

## Features
- Start, pause, and reset the stopwatch.
- Record and display lap times.
- Track fastest and slowest laps.
- Calculate average lap time.
- Responsive and user-friendly interface.
- Sage green and beige color theme.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

```text
stopwatch/

```

## Purpose
Developed to practice JavaScript timing functions, DOM manipulation, event handling, and responsive frontend design.
